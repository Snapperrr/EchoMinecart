面向 Minecraft 1.21.1 Fabric 的实验性矿车重构模组。

EchoMinecart 将矿车从单一地面交通工具扩展为可跨越地面、墙壁和天花板的轨道系统，并加入可扩充车厢、连接箱、建筑搬运、可配置加速铁轨，以及独立的环形全地形矿车。

> Experimental minecart overhaul for Minecraft 1.21.1 Fabric. The primary documentation is currently maintained in Chinese.

> [!WARNING]
> **本项目仍处于持续开发和回归测试阶段，不是稳定发行版。**
>
> 模组会移动方块和实体，也允许矿车达到远高于原版的速度。首次体验请使用测试世界，并在载入重要存档前备份。开发阶段不保证存档格式、网络协议或旧测试版本之间完全兼容。

## 主要功能

### 全向铁轨

- 玩家放置原版普通铁轨或充能铁轨时，由模组接管为对应的回声铁轨。
- 支持地面、四面墙壁和天花板铺设，并要求铁轨附着在有效方块表面。
- 普通回声铁轨支持 T 字、十字和多分支连接。
- 支持地面、墙面、天花板之间的自动过渡，以及相邻墙面的跨面转弯。
- 铁轨修复棒可循环、锁定或解除自动计算的铁轨状态，用于修正极端结构中的连接歧义。
- 充能铁轨保留通电加速、断电制动和相邻充能传播行为。
- 原版探测铁轨和激活铁轨保持原版玩法，不启用全向放置逻辑。

### 矿车运动与视角

- 矿车在墙面和天花板轨道上始终以轮面贴轨；离开有效轨道后恢复正常重力。
- 支持地面坡道、反向坡道、墙面、天花板和相邻墙面之间的姿态切换。
- 第一人称和第三人称可跟随矿车附着面；墙面视角侧转，天花板视角倒置。
- 跨面旋转使用短路径四元数平滑，减少不必要的整圈旋转。
- FOV 会按照速度、加速度、充能状态和垂直下降程度分级变化。
- 矿车行进带有可配置的低频随机颠簸；FOV 与颠簸强度可独立调整。

### 可配置加速铁轨

- 加速铁轨只使用原版十种 `RailShape`，按原版规则铺设在地面和斜坡上。
- 空手潜行右键可打开速度面板。
- 可配置范围为 `-256.0` 至 `256.0` 格/刻，默认值为 `1.0`。
- 矿车经过时直接覆盖当前速度矢量，而不是与旧速度叠加。
- 负值令矿车沿轨道切线反向行驶，`0` 令矿车停车。
- 物品图标带附魔光效；已放置方块不启用动态附魔渲染，以降低大量铺设时的开销。

### 扩充车厢与连接箱

- 拆分/合并工具可把相邻矿车手动组合为一个拉伸后的大型车厢。
- 合并车厢使用单一可见主体、扩展碰撞范围和动态座位，而不是普通列车式车节。
- 移动车厢撞到生物且存在空位时，可以将生物带入座位。
- 手持箱子潜行右键车厢可加装 27 格存储；多个箱子共享连接箱界面。
- 箱子物品可在容器内继续打开，形成箱中箱目录。
- 箱中箱内容使用内置 SQLite 数据库存储，以避免深层递归 NBT 膨胀。
- 自动岔路分支拉伸源码保留，但当前默认停用。

### 建筑搬运

- 搬运绑定工具可以绑定车厢上方的方块和实体。
- 车厢启动后，建筑会转为随车移动的显示实体，同时保存方块状态和方块实体 NBT。
- 车厢停稳后，只有目标区域完全可放置时才会整体恢复建筑。
- 活跃搬运任务写入世界 `PersistentState`，用于退出、崩溃或中断后的恢复与回滚。

### 生物绊倒

- 非玩家生物踩上回声普通铁轨或回声充能铁轨后会沿进入方向趴倒。
- 倒地生物保持无法正常导航的状态，受到伤害、死亡或状态解除后恢复。
- 原版铁轨、探测铁轨、激活铁轨和加速铁轨不会触发绊倒。

## 环形全地形矿车

环形全地形矿车是独立载具实体。矿车座舱保持在铁轨环内部，铁轨环按照载具实际位移滚动；载具整体始终以世界 Y 轴为上方，不会因为爬墙而整体侧翻。

### 基础运动

- `W/S` 控制前进和后退，`A/D` 控制载具绕世界 Y 轴转向。
- 玩家视角不直接控制车头；转向灵敏度可以在独立设置页中调整。
- 普通版与充能版具有不同加速度和最高速度。
- 普通版固定低速档；充能版安装强化离合器后可切换低速档与高速档。
- 可在地面、坡面、竖直墙壁、复杂越野表面和水面移动。
- 载具会浅浸在液面，并生成起伏、水花和对应声音。
- 黑曜石强化版本可漂浮在熔岩上，并保护乘客免受火焰伤害。
- 非熔岩免疫版本接触熔岩后会收回为掉落物。

### 尺寸与升级

- 基础环使用 8 段铁轨，视觉高度约 3 格，碰撞宽度约 1 格。
- 将基础载具放在工作台中心、外围放置 8 个同类铁轨，可升级为 5 格直径、16 段铁轨的扩大型环。
- 扩环配方会复制原物品数据，保留黑曜石强化、挡位、工具、能力模块和储物内容。
- 每辆载具最多扩环一次；扩大型环拥有更高的空转角速度和弹射上限。

### 手动离合与弹射起步

- 弹射起步仅属于安装强化离合器的充能版载具；普通版不兼容该模块。
- 按住离合器键会切断动力传递，同时保留整车原有惯性。
- 离合器配合 `W/S` 时，内部矿车会沿铁轨环正向或反向空转并逐渐提高转速。
- 松开离合器后，内部矿车保持角动量，并在下一次经过底部平衡点时接合。
- 每次成功换挡消耗 1 点离合器耐久；弹射成功时按实际传递速度消耗耐久，满强度最多消耗总耐久的约 1/3。
- 接合声量、音调、粒子、FOV 和弹射力度均按照储存动量分级。
- 弹射瞬间会按实际方向生成后喷气流、两侧卷流和贴地尘风；液面起步会生成对应飞溅。
- 对齐期间重新踩下离合器可以取消接合并恢复空转。
- 第一人称随内部矿车圆周姿态转动；第三人称摄像机保持稳定。
- 弹射 FOV 会先收缩，再在动力传递时强烈扩张，短暂保持后交还给常规速度 FOV。
- 合成强化离合器时会连续播放三次逐渐低沉的铁砧锻打声。

### 倒置飞行模式

- 空载时在车外手持重锤左键攻击环形全地形矿车，可在正常形态与倒置飞行形态之间切换。
- 倒置形态会将完整铁轨环、内部矿车和乘客横向放倒，并使用与当前环直径对应的矮扁碰撞范围。
- 形态切换使用短暂的横放/立起插值动画，不再瞬间硬切模型角度。
- 悬停时由外部铁轨环持续旋转；踩下离合器后，外环按照内部矿车的转速比例逐渐卸载动力，内部矿车接近约 86% 转速时外环才完全停止。
- 按住离合器配合 `W` 时，内部矿车逆时针蓄转；达到约 62% 转速后开始爬升。
- 接近起飞阈值时，飞行器整体会出现低幅不规则振动作为临界反馈。
- 踩下离合器后飞行器立即开始受重力下降；配合 `S` 反向蓄转会进一步加快下降。
- 松开离合器并完成归位后，内部矿车停止在基准位置，转速转移给铁轨环；铁轨环持续旋转并维持悬停。
- 外环悬停旋转带有持续矿车底噪；达到起飞转速时播放气流声，接触地面或液面时播放对应着陆反馈。
- 着陆后外部铁轨环会快速制动；水面会作为有效着陆面并保持浅吃水漂浮。
- 只有真正离开地面或液面支撑后，`W/S` 水平前进或后退才会生效；`A/D` 始终用于转向。
- 真正起飞后，糖模块可在空中沿当前机头方向释放冲刺；着陆前仍可使用 `A/D` 微调方向。
- 兔子脚模块在飞行模式下改为短距离紧急爬升，不改变内部矿车转速、离合器阶段，也不能跳过正常起飞过程。
- 重锤模块在飞行模式下使用独立的 `X` 蓄力条：蓄力越高，强制下降速度和持续距离越大；蓄满后会持续下砸直至接触地面或液面。
- 第一人称跟随横卧矿车的圆周姿态；第三人称以飞行器圆心作为视焦点，减少爬升时的画面抖动。
- 只有扩大型倒置飞行器可以手持矿车潜行右键追加矿车模块，最多额外安装 7 辆。
- 所有内部矿车按总数量等分 360 度排列；每辆额外矿车增加约 30% 的水平和垂直动力。
- 切回正常全地形形态后，额外矿车数量继续保留，但不会显示或参与普通模式运动。

### 工具与能力模块

按 `V` 打开工具、能力模块和储物界面。

| 模块/槽位 | 效果 |
| --- | --- |
| 3 个通用工具槽 | 自动选择适合目标方块的工具并消耗对应耐久 |
| 箱子 | 解锁持久化的 27 格储物 |
| 兔子脚 | 全地形模式解锁蓄力跳跃；飞行模式解锁独立的紧急爬升 |
| 糖 | 解锁 `R` 蓄力冲刺；飞行时沿当前机头方向施加推力 |
| 重锤核心或重锤 | 解锁全地形模式即时下砸、飞行模式蓄力下砸和速度撞击伤害 |
| 强化离合器 | 充能版专用；解锁高速档和弹射起步；共 360 点耐久 |

手动采矿：

- 在装备界面点击工具栏中的镐图标启动采矿模式，再关闭界面。
- 按住鼠标左键会持续挖掘准心命中位置所在平面的 `3 x 3` 区域。
- 基础环的射线最远延伸至铁轨环外缘之外 5 格；扩大型环额外增加 2 格。
- 当前 `3 x 3` 平面全部破坏后，可在同一 tick 继续结算下一层，减少连续掘进时的停顿。
- 安装工具不再禁止爬墙，采矿方向也不再与载具朝向绑定。
- 采矿模式会接管鼠标左键，关闭后恢复原版攻击和挖掘。

补充规则：

- 跳跃、冲刺和飞行下砸拥有互不混用的蓄力条、满蓄动画与退场动画。
- 冲刺尾流从铁轨环后缘产生，并锁定释放瞬间的三维行进方向。
- 下砸落地会读取实际方块状态并生成对应碎屑。
- 下砸进入水或熔岩时会生成大量液体粒子和专属声音。
- 重锤模块的速度撞击伤害采用低速线性值与高速指数曲线中的较高值。
- 扩大型充能环高速档满转速弹射对应 `500` 点原始伤害上限；护甲和抗性仍按原版规则减伤。
- 撞击生物不会消耗载具速度，但同一目标具有短暂重复伤害冷却。
- 玩家乘坐任意环形全地形矿车时免疫摔落伤害。
- 玩家乘坐时，载具自身不会再截获准心射线，可正常攻击、挖掘和放置方块。

### 数据与回收

- 离车后空手潜行右键可将载具收回物品栏。
- 回收物品保留环尺寸、熔岩免疫、挡位、工具、能力模块、离合器和储物内容。
- 手持箱子潜行右键载具也可以直接安装箱子模块。
- 四种基础物品共用同一载具实体；扩环状态通过物品和实体数据持久化。

## 安装

### 运行要求

| 依赖 | 要求 |
| --- | --- |
| Minecraft | `1.21.1` |
| Fabric Loader | 最低 `0.16.0`；当前开发环境使用 `0.19.3` |
| Fabric API | 当前开发环境使用 `0.116.13+1.21.1` |
| Java | 21 |

SQLite JDBC 已打包进构建产物，不需要单独安装。

### 安装步骤

1. 为 Minecraft 1.21.1 安装 Fabric Loader。
2. 将对应版本的 Fabric API 放入 `mods` 文件夹。
3. 从 [GitHub Releases](https://github.com/Snapperrr/EchoMinecart/releases) 获取 EchoMinecart jar，或按照[构建与开发](#构建与开发)自行构建。
4. 将 EchoMinecart jar 放入客户端和服务端的 `mods` 文件夹。
5. 使用新世界或已备份存档进行首次测试。

> [!IMPORTANT]
> 模组包含客户端渲染、按键和界面逻辑，也包含服务端物理、存储和世界状态逻辑。多人游戏时，客户端与服务端必须安装相同版本。

## 基本操作

所有按键都可以在 Minecraft 原版“控制”设置中重新绑定。

| 默认操作 | 用途 |
| --- | --- |
| `O` | 打开普通矿车 FOV/颠簸设置 |
| 环形全地形矿车内按 `W/S` | 前进/后退 |
| 环形全地形矿车内按 `A/D` | 绕世界 Y 轴转向 |
| 安装强化离合器后按 `G` | 切换充能版低速档/高速档 |
| 环形全地形矿车内按 `V` | 打开工具、能力和储物界面 |
| 装备界面点击镐图标 | 开启/关闭手动采矿 |
| 采矿开启后按住鼠标左键 | 持续挖掘准心位置的 `3 x 3` 平面 |
| 安装强化离合器后按左 `Alt` + `W/S` | 踩下离合器并让内部矿车正向/反向空转 |
| 松开左 `Alt` | 等待内部矿车归位并弹射起步 |
| 车外手持重锤左键空载环形全地形矿车 | 切换正常形态/倒置飞行形态 |
| 扩大型倒置飞行器上手持矿车潜行右键 | 追加一辆内部矿车模块 |
| 安装兔子脚后按住/松开空格 | 蓄力并释放跳跃 |
| 安装糖后按住/松开 `R` | 蓄力并释放冲刺，冷却 30 tick |
| 全地形模式安装重锤模块且离地后按 `X` | 立即下砸并产生材质化冲击反馈 |
| 飞行模式真正起飞后按住/松开 `X` | 蓄力下降；满蓄后持续下砸至地面或液面 |
| 加速铁轨上空手潜行右键 | 打开固定速度设置面板 |
| 手持箱子潜行右键环形全地形矿车 | 安装箱子模块 |
| 离车后空手潜行右键环形全地形矿车 | 回收载具及其全部数据 |
| 拆分/合并工具依次潜行右键两个矿车 | 合并车厢或切开指定连接 |
| 车厢上空手潜行右键 | 打开连接箱存储 |
| 搬运绑定工具潜行右键矿车 | 绑定或管理建筑搬运 |
| 充能棒潜行右键矿车 | 沿玩家指向启动矿车 |
| 铁轨修复棒右键回声铁轨 | 循环并锁定手动铁轨状态 |
| 铁轨修复棒潜行右键回声铁轨 | 锁定或解除当前自动状态 |

物品可在创造模式的红石或工具分类中找到。

## 合成与注册 ID

### 环形全地形矿车配方

所有配方均使用标准 `3 x 3` 工作台：目标载具或矿车位于中心，其余材料填满外围 8 格。

| 配方 | 外围材料 | 中心材料 |

## 构建与开发

### 本地构建

克隆仓库后，在项目根目录运行：

Windows：

```powershell
.\gradlew.bat build
```

Linux / macOS：

```bash
./gradlew build
```

构建产物：

```text
build/libs/echo-minecart-1.0.0.jar
build/libs/echo-minecart-1.0.0-sources.jar
```

启动开发客户端：

```powershell
.\gradlew.bat runClient
```

### 技术组成

- Fabric Loader、Fabric API 和 Yarn Mappings。
- Java 21。
- Mixin 用于接入原版矿车、相机、容器和实体行为。
- Data Tracker 与自定义网络载荷用于载具状态同步。
- `PersistentState` 用于建筑搬运任务恢复。
- NBT/数据组件用于环形全地形矿车工具、模块、尺寸和储物持久化。
- 内置 SQLite JDBC 用于箱中箱内容存储。

### 代码结构

```text
src/main/java/com/xc/echominecart
├── rail/          铁轨方块、连接判定、贴附物理和加速铁轨
├── ringvehicle/   环形全地形矿车实体、物品、配方、物理和持久化
├── carriage/      扩充车厢、座位、碰撞与加装箱子
├── haul/          建筑绑定、搬运、恢复和回滚
├── trip/          生物绊倒状态机
├── storage/       箱中箱 SQLite 存储
├── screen/        服务端容器与 ScreenHandler
├── client/        渲染、HUD、相机、FOV、声音和设置界面
├── network/       客户端与服务端自定义载荷
└── mixin/         原版行为注入点
```

### 回归测试建议

仓库当前以人工场景回归为主。涉及轨道、矿车物理或相机的修改，至少验证：

- 地面直轨、弯轨、一格坡道和连续坡道。
- 正向坡道、反向坡道、墙面和天花板的双向过渡。
- 相邻墙面跨面转弯及轨道尽头脱离。
- 普通速度、充能高速和加速铁轨极端速度。
- 第一人称、第三人称和无人乘坐三种观察方式。
- 普通矿车、手动合并车厢、基础与扩大型环形全地形矿车。
- 环形全地形矿车的跳跃、冲刺、即时下砸，以及飞行模式的紧急爬升、空中冲刺和独立蓄力下砸。
- 飞行能力只能在真正离开地面或液面后使用，并且不会改变内部矿车转速或提前进入飞行状态。
- 三工具自动选择、采矿开关、不同观察方向的 `3 x 3` 平面和两种环尺寸的极限射程。
- 普通版与未安装离合器的充能版保持低速档且不能弹射。
- 世界保存/重载后的箱子、建筑搬运和环形全地形矿车数据。

## 已知限制

- 项目仍在持续制作，正式稳定版前可能调整玩法、存档格式和网络协议。
- 极高的加速铁轨数值或满转速弹射会显著增加区块加载、碰撞检测和网络同步压力。
- 建筑搬运期间使用显示实体模拟方块；红石和部分特殊方块不会在移动时实时运行。
- 极端紧凑的跨面轨道、连续斜坡或复杂转角仍可能出现短暂视觉抖动。
- 基础与扩大型环形全地形矿车使用近似 `3 x 3 x 1` 和 `5 x 5 x 1` 的纵向碰撞范围；狭窄地形、内凹转角和未加载区块边缘需要重点测试。
- 手动采矿每 tick 最多处理两个连续的 `3 x 3` 平面；持续掘进会增加方块更新和掉落物开销。
- 自动岔路分支拉伸当前默认停用。
- 旧测试版本中的 `echo_transition_rail` 已移除，旧存档中的对应方块会消失。
- 与其他重写矿车、铁轨、相机、乘客姿态或容器逻辑的模组可能存在兼容冲突。

## 问题反馈

提交 [Issue](https://github.com/Snapperrr/EchoMinecart/issues) 前请先在仅安装 Fabric API 与 EchoMinecart 的环境中复现。Issue 建议包含：

1. Minecraft、Fabric Loader、Fabric API 和 EchoMinecart 版本。
2. 单人游戏或专用服务器环境。
3. 完整模组列表，以及是否安装其他矿车、物理、渲染或相机模组。
4. 最小可复现轨道/地形结构和逐步操作。
5. 预期结果与实际结果。
6. `logs/latest.log`、崩溃报告，以及必要的截图或视频。

铁轨连接问题还应说明：

- 铁轨附着面和相邻方块结构。
- 矿车进入问题位置前的行进方向与速度。
- 铁轨是否通电。
- 问题是否只在单向行驶时出现。
- 是否使用铁轨修复棒锁定过状态。

建筑搬运或存储问题请同时说明世界是否在任务进行中退出、崩溃或强制关闭。
