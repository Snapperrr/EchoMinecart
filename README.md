# EchoMinecart

![Minecraft](https://img.shields.io/badge/Minecraft-1.21.1-62B47A)
![Fabric](https://img.shields.io/badge/Loader-Fabric-DBD0B4)
![Java](https://img.shields.io/badge/Java-21-E76F00)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

EchoMinecart 是一个面向 Minecraft 1.21.1 Fabric 的实验性矿车重构模组。它扩展了铁轨的铺设空间、矿车运动方式、车厢尺寸、连接箱存储、建筑搬运和乘坐视角，并提供可配置的加速铁轨。

> [!WARNING]
> 项目仍在开发和回归测试中。部分功能会移动方块、实体或以高速度驱动矿车。请优先使用测试世界，并在载入重要存档前做好备份。

## 功能概览

### 全向铁轨

- 原版普通铁轨和充能铁轨会被接管为回声铁轨。
- 支持地面、四面墙壁和天花板铺设。
- 普通回声铁轨支持 T 字、十字和多分支连接。
- 支持地面、墙面、天花板之间的自动过渡，以及相邻墙面的跨面转弯。
- 矿车在墙面和天花板行驶时保持轮面贴轨，轨道中断后恢复正常重力。
- 充能铁轨保留通电加速和断电制动行为，并支持贴附轨道。
- 原版探测铁轨和激活铁轨保持原版行为，不启用全向玩法。

注册 ID：

| 内容 | ID |
| --- | --- |
| 回声铁轨 | `echominecart:echo_rail` |
| 回声充能铁轨 | `echominecart:echo_powered_rail` |

### 可配置加速铁轨

- `echominecart:speed_rail` 使用原版普通铁轨的十种 `RailShape`，只能按原版规则铺在地面和斜坡上。
- 空手潜行右键可打开速度设置面板。
- 默认速度为 `1.0` 格/刻，可设置为 `-256.0` 至 `256.0` 格/刻。
- 经过时直接覆盖矿车速度矢量，不与旧速度叠加。
- 负值会令矿车沿轨道切线反向行驶，`0` 会令矿车停车。
- 同一格轨道具有短暂重复触发保护，避免负值速度在一格内反复翻转。
- 物品图标带附魔光效；已放置方块不使用动态附魔渲染，以控制大量铺设时的性能开销。

### 扩充车厢与箱子

- 玩家可使用拆分/合并工具把相邻矿车手动组合为一个拉伸后的大型车厢。
- 合并车厢使用单一可见主体和同步扩展的碰撞范围，而不是显示为普通列车车节。
- 座位数量随车厢覆盖格数量变化。
- 移动车厢撞到生物且存在空位时，可将生物带入座位。
- 潜行并手持箱子右键车厢，可占用一个位置加装 27 格存储。
- 多个加装箱子共享连接箱界面，内容随矿车 NBT 持久化。
- 自动岔路分支拉伸目前处于停用状态，源码保留但默认不运行。

### 连接箱与箱中箱

- 相邻世界箱子可组成连接箱。
- 箱子物品可在容器界面内继续打开，形成箱中箱目录。
- 箱中箱内容使用 SQLite 存储，避免深层递归 NBT 膨胀。
- 支持目录箱连接、漏斗输入、排序、重命名和掉落清理。
- 这部分功能来自维护者早期 Chest 模组的整合与重构。

### 建筑搬运

- 使用搬运绑定工具可绑定车厢上方的方块和实体。
- 车厢启动后，方块会转换为随车移动的显示实体，原始状态和方块实体 NBT 会被保存。
- 车厢停稳后，仅在目标区域完全可放置时才会整体恢复建筑。
- 活跃搬运任务写入世界 `PersistentState`，用于崩溃、退出或中断后的恢复与回滚。

### 生物绊倒

- 非玩家生物踩上回声普通铁轨或回声充能铁轨后会被绊倒。
- 生物会沿进入铁轨时的方向趴倒，并保持倒地状态。
- 受到伤害、死亡或状态解除后会恢复导航。
- 原版铁轨、探测铁轨、激活铁轨和加速铁轨不会触发绊倒。

### 乘坐视角

- 第一人称和第三人称视角会跟随矿车所在的贴附面旋转。
- 墙面行驶时视角侧转，天花板行驶时视角倒置。
- 跨面旋转采用短路径四元数平滑，减少不必要的整圈旋转。
- 支持按速度分级的 FOV 增强和低频随机颠簸。
- FOV 与颠簸强度可在游戏内设置，并保存到 `config/echominecart-client.properties`。

## 运行环境

| 依赖 | 版本 |
| --- | --- |
| Minecraft | 1.21.1 |
| Fabric Loader | 0.19.3，最低兼容声明为 0.16.0 |
| Fabric API | 0.116.13+1.21.1 |
| Java | 21 |

模组同时包含客户端视觉逻辑和服务端玩法逻辑。多人游戏时，客户端与服务端都应安装相同版本。

## 安装

1. 安装 Minecraft 1.21.1 对应的 Fabric Loader。
2. 安装兼容版本的 Fabric API。
3. 从 GitHub Releases 下载构建好的 EchoMinecart jar，或按照下方步骤自行构建。
4. 将 jar 放入客户端和服务端的 `mods` 文件夹。
5. 首次测试请使用新世界或已备份存档。

## 基本操作

| 操作 | 用途 |
| --- | --- |
| `O` | 打开 EchoMinecart 客户端设置 |
| 加速铁轨上空手潜行右键 | 打开固定速度设置面板 |
| 拆分/合并工具依次潜行右键两个矿车 | 合并车厢或切开指定连接 |
| 车厢上手持箱子潜行右键 | 加装箱子 |
| 车厢上空手潜行右键 | 打开连接箱存储 |
| 搬运绑定工具潜行右键矿车 | 绑定或管理上方建筑搬运 |
| 充能棒潜行右键矿车 | 沿玩家指向启动矿车 |
| 铁轨修复棒右键回声铁轨 | 循环并锁定手动铁轨状态 |
| 铁轨修复棒潜行右键回声铁轨 | 锁定或解除当前自动状态 |

物品可在创造模式的红石或工具分类中找到。

## 构建

克隆仓库后，在项目根目录运行：

Windows：

```powershell
.\gradlew.bat build
```

Linux / macOS：

```bash
./gradlew build
```

构建产物位于：

```text
build/libs/echo-minecart-1.0.0.jar
```

启动开发客户端：

```powershell
.\gradlew.bat runClient
```

## 项目结构

```text
src/main/java/com/xc/echominecart
├── rail/       铁轨方块、连接判定、贴附物理和加速铁轨
├── carriage/   扩充车厢、座位、碰撞与加装箱子
├── haul/       建筑绑定、搬运、恢复和回滚
├── trip/       生物绊倒状态机
├── client/     渲染、相机、FOV、声音和设置界面
├── network/    客户端与服务端同步载荷
├── storage/    箱中箱 SQLite 存储
└── mixin/      原版矿车、相机、容器和实体行为注入点
```

## 已知限制

- 项目仍在持续制作，玩法、存档格式和网络协议在正式稳定版前可能调整。
- 极高的加速铁轨数值可能令矿车快速跨越区块，并增加区块加载、碰撞检测或服务端同步压力。
- 建筑搬运途中使用显示实体模拟方块，红石和部分特殊方块不会在移动时实时运行。
- 极端紧凑的跨面轨道、连续斜坡或复杂转角仍可能出现短暂视觉抖动。
- 旧测试版本中的 `echo_transition_rail` 已移除，旧存档中的对应方块会消失。
- 与其他重写矿车、铁轨、相机或实体乘坐逻辑的模组可能存在兼容冲突。

## 问题反馈

提交 Issue 时请尽量包含：

1. Minecraft、Fabric Loader、Fabric API 和 EchoMinecart 版本。
2. 单人游戏或专用服务器环境，以及是否安装其他矿车或渲染模组。
3. 可重复触发问题的最小轨道结构和操作步骤。
4. 预期结果与实际结果。
5. `logs/latest.log`、崩溃报告，以及必要的截图或视频。

对于铁轨连接问题，请同时说明铁轨附着面、矿车行进方向、是否通电，以及问题是否只在单向行驶时出现。

## 贡献

欢迎提交 Issue、测试记录、文档修正和 Pull Request。涉及轨道连接或矿车物理的修改，请尽量提供以下回归结果：

- 地面直轨、弯轨和一格坡道。
- 地面与墙面、墙面与天花板的双向过渡。
- 相邻墙面跨面转弯。
- 普通速度与充能高速两种情况。
- 第一人称、第三人称和无人乘坐三种观察方式。
- 单矿车与手动合并车厢。

请保持修改范围清晰，不要在同一个 Pull Request 中混入无关重构。
