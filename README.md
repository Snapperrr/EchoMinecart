# EchoMinecart

EchoMinecart 是一个面向 Minecraft 1.21.1 Fabric 的矿车与铁轨重做模组。项目从同目录的 `Chest` 模组迁移了箱子连接、箱中箱、连接箱 UI、SQLite 存储、漏斗绑定和掉落清理逻辑，并在此基础上重写了铁轨、扩充车厢、调试工具和搬运绑定。

建议只在测试世界或已备份存档中验证。矿车扩充和建筑搬运会移动实体与方块，属于高影响玩法。

## 环境

- Minecraft 1.21.1
- Fabric Loader 0.19.3
- Fabric API 0.116.13+1.21.1
- Java 21

## 构建

在 `EchoMinecart` 目录运行：

```powershell
.\gradlew.bat build
```

构建产物：

```text
build/libs/echo-minecart-1.0.0.jar
```

## 代码结构

矿车/铁轨层按职责分包，Chest 迁移的基础设施保持原样：

```text
com.xc.echominecart
├── EchoMinecartRegistry      注册中心：方块/物品/事件分发/寻路注册
├── rail/                     全向铁轨方块族 + 矿车轨道物理
│   ├── OmniRailBlock         六面贴附、全向连接、统一拐角候选规则
│   ├── PoweredOmniRailBlock  充能轨（链式充能、加速/刹车）
│   ├── DetectorOmniRailBlock 探测轨（红石 + 比较器输出）
│   ├── ActivatorOmniRailBlock 激活轨
│   └── RailPhysics           吸附、跨面拐角速度重投影、轨道尽头释放
├── trip/TripManager          生物绊倒状态机
├── carriage/                 扩充车厢
│   ├── CarriageManager       并查集合并、岔路拉伸、座位、拆分工具逻辑
│   ├── CarriageShape         车厢几何（座位格、碰撞盒）
│   ├── CartAttachment        单节轮组数据（箱子页、NBT 持久化）
│   └── CartGroupChestInventory + CartChestScreenHandlerFactory
├── haul/HaulManager          搬运绑定（扫描/拾取/随行/放回）
├── item/                     两个调试工具的 Item 类
└── mixin/                    最小化注入点（物理挂钩、NBT、渲染、相机/FOV）
```

## Chest 迁移功能

- 世界箱子可连接成大箱子组。
- 箱子物品可在箱子 UI 内继续打开，形成箱中箱目录。
- 箱中箱内容使用 SQLite 存储，避免递归 NBT 膨胀。
- 相邻箱子物品可组成双目录箱。
- 漏斗可优先输入到绑定目录箱。
- 打破箱子时会递归释放深层物品并清理存储 ID。

## 全向铁轨

玩家放置原版普通铁轨、充能铁轨、探测铁轨或激活铁轨时，会被替换成对应回声铁轨：

- `echominecart:echo_rail`
- `echominecart:echo_powered_rail`
- `echominecart:echo_detector_rail`
- `echominecart:echo_activator_rail`

四种铁轨都已加入 `minecraft:rails` 方块/物品标签。

### 六面贴附与全向连接

- 地面、四面墙、天花板都可以放置；放置必须有真实完整方块的附着面，铁轨不能叠在铁轨上。
- 普通铁轨在同一贴附面内支持 T 字、十字与任意多分叉全连接，方块状态里的六向连接布尔量直接驱动模型显示所有分支。
- **跨面衔接是自动的，不需要过渡方块**：铁轨连接判定对每个面内切线方向 d（法线 n）检查五个候选位置——直线 `(P+d, n)`、内角 `(P+n, -d)` 与 `(P+d, -d)`、对角内角 `(P+n+d, -d)`、外角 `(P+d-n, d)`。全部自对称，地面↔墙面、墙面↔天花板（含墙顶与天花板齐平、隔一个对角空格的常见摆法）、绕竖直棱的墙面↔墙面内外角都会自动连上。
- **地面通向墙面的内角会翘起**：该格的 SHAPE 置为 ascending 并渲染原版 45° 坡道模型（四种铁轨都有对应坡道贴图，充能/探测/激活轨含通电变体）。坡道格由自管物理接管：水平速度保留、高度按 45° 轮廓抬升、无动力时顺坡滑回——不走原版斜坡物理（它会把矿车提前搬进墙体撞停，还会把横穿的矿车速度投影清零）。
- **接触自愈**：矿车驶过的每格铁轨都会按当前连接公式重算方块状态，旧版本放置的存量铁轨开一遍就会自动补上缺失的连接（如对角内角）。
- **墙面/天花板上的面内拐弯**：同一面内的 L/T 弯会在格中心把矿车整体转向另一条分支；前方没有可用连接并越过边缘时会释放贴附控制、恢复重力，让矿车自然脱轨下落。墙面模型按连接方向区分竖直/水平两种贴片，拐角处两段交叉显示。

### 矿车物理

物理主权划分明确：地面轨交给原版物理（只补充充能加减速与岔路转向）；
贴附轨（墙/顶）与拐角过渡完全由 `RailPhysics` 接管——原版 `moveOnRail`
会把矿车 Y 拉回轨道格、抹掉垂直速度，因此贴附态直接通过 mixin 取消它，
位移由模组自己积分；渲染侧同样豁免了 `snapPositionToRail` 的位置吸附。

- **轨道线约束**：贴附态速度投影到当前轨道切线（而不是整个贴附面），
  所以横穿墙面的水平轨不会掉，竖直爬升/天花板行驶不会被原版重力拉脱轨。
- **主动拐角过渡**：行进方向的连接是内角/外角时，矿车被主动移到伙伴轨道
  的入口棱边。速度规则封闭对称——内角：新速度 = +旧法线×速度；外角：
  新速度 = −旧法线×速度。地面↔墙面↔天花板全部走同一条规则。
- 墙面/天花板轨：贴附段关闭原版重力；轨道到头或前方没有可用连接时释放附着控制、恢复重力，让矿车自然掉回普通世界物理。充能轨（通电）只沿矿车当前行进方向加速、不干预方向，静止矿车不会被推动（用充能棒启动）。
- 充能轨未通电时刹车；激活轨按红石状态触发矿车激活行为；探测轨输出红石与比较器信号。
- 岔路格（连接数 > 2）同样纳入自管物理：原版 moveOnRail 的 SHAPE 只能表达一条
  轴线，会把垂直方向的速度清零；自管积分让矿车和分支探针能真正横穿十字路口。
- 轮面始终朝向铁轨：渲染按「撤销原版 yaw → 世界系贴面旋转 → 面内行进朝向」
  的顺序复合，乘客用 bodyYaw 共轭做同样的贴面旋转。
- 乘客座位偏移是相对矿车的整格向量，随矿车连续移动，不会逐格弹跳。

### 客户端视角与沉浸效果

- 第一人称和第三人称相机都会跟随矿车贴附面旋转：墙面横行会侧向、天花板行驶会倒置，垂直上下时视角不会再锚到支撑方块内部。
- 相机锚点按铁轨表面法线外推到安全眼位；第三人称 `clipToSpace` 在更新后的相机方向上重新计算，避免防穿墙射线沿旧方向把镜头推回墙内。
- 贴附面变化使用短路径四元数平滑：目标姿态会先进入距离当前相机姿态更近的四元数半球，再用 `slerp` 插值，尽量减少封闭 360° 过山车轨道里的长路径旋转。这里保留短路径方案，不使用连续目标跟踪。
- 玩家鼠标转头仍然即时响应；平滑只作用在矿车/铁轨导致的基准姿态变化上。
- 坐矿车时有分级 FOV 增强：垂直下坡最大，下坡充能轨次之，平路充能轨再次，普通高速行驶按速度渐进；FOV 必须达到最低速度才会触发，静止停在充能轨上不会放大。
- 矿车切换贴附面或主要行进方向时，FOV 会先平滑回落，再按当前速度和轨道重新蓄起，避免面切换瞬间还顶着上一段轨道的冲刺视野。
- 第一人称加入轻微、不完全规律的侧向颠簸，使用低频噪声混合而不是固定节拍，强度低于明显晃屏，只用于保留行驶呼吸感。
- FOV 增强和颠簸强度可以在游戏内调节：默认按 `O` 打开 EchoMinecart 设置，也可以从暂停菜单右下角进入。FOV 强度范围 `0%`-`300%`，默认 `145%`；颠簸强度范围 `0%`-`250%`，默认 `100%`，配置会保存到 `config/echominecart-client.properties`。
- 乘客实体在墙面/天花板轨道上会使用铁轨外侧安全点采样光照；同时屏蔽原版“头在方块里”的黑色遮罩误判，避免玩家模型或第一人称画面突然发黑。
- 墙面和天花板轨道上的矿车行进声按完整三维速度计算，竖直爬升/下降不会再因为水平速度接近 0 而静音。

## 生物绊倒

- 非玩家生物踩到铁轨所在格或脚下铁轨格时被绊倒：面朝下扑倒在轨道中心，身体沿走上铁轨时的行进方向。姿态由 `TripSyncPayload` 明确同步，客户端渲染层直接旋转出趴倒姿势，不依赖原版泳姿；玩家中途进入追踪范围也会补发状态。
- 绊倒后关闭重力、清零速度、导航停止、每次巡检强制按住，受到任意伤害或死亡才解除。
- 解除时重置导航路径，生物起身后立刻重新决策，不会带着过期路径发呆。
- 原版寻路会绕开铁轨；回声铁轨已通过 Fabric `LandPathNodeTypesRegistry` 注册为普通可行走地面，僵尸等生物会把铁轨当路走，从而踩进陷阱。

## 扩充车厢

- **矿车不会自动合并**：合并只通过拆分/合并工具进行——潜行右键依次点选两个 4 格以内的轮组即合并为一节车厢；同一节车厢里的两个轮组则被切开。手动链接随矿车 NBT 持久化，重启不丢。锚点由多数投票选举保持稳定。
- 合并后只保留一个可见锚点矿车，其余轮组作为隐藏尺寸模块存在（同样跳过原版轨道物理，由管理器逐 tick 归位）。
- 车厢覆盖格由服务端通过 `CarriageSyncPayload` 下发给客户端，客户端按同步数据拉伸锚点矿车模型，不做本地推断。
- **分叉分身**：车厢驶过多分叉铁轨时，向每个未被占用的分支派出隐形的"分支探针车"。探针车是真实矿车，独立沿自己的分支行驶（含墙面/天花板分支），走过的轨迹格计入车厢覆盖格——车体像树枝一样沿所有分支持续拉伸，每条分支路径都有真实运动。探针车轨迹超限、停滞、脱轨或与车厢其他部分汇合时被吸收（车体缩短），途经更深的分叉还会继续分裂（组内探针上限 6）。
- 座位只放在真实覆盖格上（车体、轨道、探针轨迹），不做包围盒填充，不会出现悬空座位。
- 座位数 = 覆盖格数 − 加装箱子数。移动中的扩充车体碰到生物且有空位时自动拉上车；车体缩短导致超员时按座位顺序甩下多余乘客。

### 加装箱子

- 潜行 + 手持箱子右键车体：占用一个座位并加装一页真实的 27 格存储；加装箱子会作为车体绑定渲染的一部分显示在对应座位格上，随合并矿车的拉伸、转向和贴附面旋转一起运动。
- 潜行 + 空手右键任意车体：打开整节车厢全部箱子拼成的连接箱页面（沿用 Chest 迁移的滚动 UI，多页像一个大箱子连续显示）。
- 箱子数量与内容随矿车实体 NBT 持久化；矿车被打掉时掉落箱子和全部内容物。

## 工具

### 矿车拆分/合并工具

潜行右键依次点选两个矿车轮组：

- 同一节车厢里的两个轮组：切开这对连接；加装箱子按 27 格一页跟随所在轮组，各自保留内容。
- 不同车厢的两个轮组（距离 4 格以内）：合并为同一节车厢。手动链接随 NBT 持久化。

### 充能棒

潜行右键矿车：沿"玩家 → 矿车"方向推动矿车（力度 0.5），用于在没有充能轨的地方直接启动矿车，墙面/天花板轨上同样有效（速度会被轨道线约束投影到可行方向）。

### 搬运绑定工具

潜行右键矿车：

- 扫描整节车厢每个座位格正上方最多 48 格、总计最多 768 个方块，连同范围内实体一起绑定。
- 车厢真正开动后才拾取：方块换成随车移动的 BlockDisplay，原方块暂时移除；实体关重力随行。箱中箱和普通箱子会先抑制原版掉落流程，避免搬运开始时爆物品或复制物品。
- 车厢停稳约 2 秒后按相对位置放回；只要有一个目标位置被占用或放置条件不满足，整批货物拒绝放下，继续跟车等待下一次停稳。

## 已知限制

- 手动允许合并的选择（MANUAL）与搬运绑定不跨重启；箱子内容和拆分禁令会随矿车 NBT 保存。
- 旧存档里的 `echo_transition_rail`（过渡铁轨）方块已从模组移除，加载时会消失；旧铁轨因状态属性精简会重置连接，邻格更新后自动恢复。
- 搬运绑定的方块使用 Display 实体模拟，红石状态、方块实体动画和部分特殊方块行为不会在搬运途中实时运行；停稳放回后恢复为真实方块。
- 仍在迭代观察的轨道手感问题：垂直面衔接正常连续下坡、以及地面平路直接衔接连续下坡时，矿车在下坡前几格偶尔仍可能出现类似“走楼梯”的轻微抽搐；垂直面衔接下坡时，玩家视角也可能在部分单向路线中看向车尾。这两个问题上一次尝试修复已回退，当前 README 按回退后的代码状态记录。
